## <a name="intro"></a>🔍 프로젝트 소개 (Project Introduction)

## "AI가 내 소비를 분석해서 잔소리하고, 또래와 비교해주는 소비 습관 코칭 앱, 땡그랑" ##

땡그랑은 잔소리 마스코트가 AI로 분석한 소비 패턴을 바탕으로 코칭해주는 소비 습관 관리 앱입니다.  
감정 태그 기반 변동지출 관리, 또래와의 저축·지출·수입 비교, 저축 랭킹 커뮤니티, 위치 기반 중고마켓까지 아우르는 종합 소비 코칭 플랫폼입니다.

---

### 📌 핵심 비즈니스 모델 및 차별성 (Business Core Value)

* 🐷 **감정 이입형 소비 분석**
  * 잔소리 마스코트 캐릭터를 통해 소비 패턴에 대한 공감과 피드백을 제공하여 지속적인 앱 사용 동기를 부여합니다.
* 🏷️ **감정 태그 기반 변동지출 관리**
  * 단순 금액 기록을 넘어 소비 시 감정을 함께 기록하여, 사용자가 스스로의 소비 패턴과 감정의 연관성을 인식하도록 돕습니다.
* 👥 **또래 비교 및 저축 랭킹 커뮤니티**
  * 동일 연령대/직군 사용자와의 저축률·지출·수입 비교, 랭킹 시스템을 통해 건전한 소비 동기를 자극합니다.
* 🛒 **위치 기반 신뢰 중고마켓**
  * GPS 기반 동네 인증을 통해 직거래 안전성을 높인 위치 기반 중고거래 기능을 제공합니다.

---

### <a name="features"></a>🛠️ 주요 기능 (Key Features)

#### 1. 지출/수입 관리 (임예림 담당)
* 영수증 OCR 자동 인식 및 내역 저장
* 카테고리별/커스텀 카테고리 관리, 감정 태그 기록
* 카드포인트 조회, 연말정산 시뮬레이션

#### 2. 공통·인증·마이페이지 (김은동 담당)
* 온보딩, 로그인/회원가입, 홈 대시보드
* 프로필/알림/잔소리 캐릭터 설정
* AI 상담 채팅 및 상담 이력 관리

#### 3. 예산·통계·구독·여행 (성기필 담당)
* 카테고리별 집계, 감정 태그 통계, 예산 설정/대비 지출
* 구독 관리, 여행 지출 입력·정산

#### 4. 마켓·거래 및 커뮤니티 (안혜진 담당)
* 커뮤니티 홈, 저축비율 공유, 랭킹, 또래비교 통계
* 마켓 홈, 상품 등록/상세, 가격비교, GPS 기반 동네 인증
* 실시간 채팅(스티커 지원)

#### 5. 공동관리·미션·아바타·소비심리테스트 (이태화 담당)
* 그룹 생성/참여, 공동지출 관리
* 미션/출석체크/포인트 상점/아바타 커스터마이징
* 소비심리테스트, 맞춤 예산 추천

## <a name="roles"></a>💪🏼 역할 분담

### 임예림 — 지출 입력·기록 + 카드포인트·연말정산
- **담당 컬렉션:** expenses, categories, customCategories, cardPoints(+history), yearEndSimulations
- **화면:** 내역입력(기본/계산기/퉁치기), 영수증 촬영업로드 및 OCR 파싱, 내역목록/상세, 카테고리 관리, 카드포인트, 연말정산 시뮬레이션 등 12개

### 김은동 — 공통·인증 + 마이페이지 + AI상담
- **담당 컬렉션:** users
- **화면:** 스플래시, 온보딩, 로그인/회원가입, 홈 대시보드, 마이페이지/프로필/알림/캐릭터 설정, AI 상담 채팅 및 이력 등 11개

### 성기필 — 예산·통계 + 구독·여행
- **담당 컬렉션:** budgets, monthlySummary, subscriptions, trips
- **작업화면:** 월간브리핑,예산관리(카테고리별예산관리,전체예산관리),정기결제관리(구독),여행(여행 생성,여행목록 관리,여행공동정산,여행리포트),소비통계(카테고리분석,감정태그분석)
- **구현 주요기능:**
- 카테고리 예산관리 및 예산초과 알림 기능 구현
- 여행모드생성,여행별 지출관리,공동정산기능구현
- 월간브리핑(소비분석,카테고리통계,감정태그분석)기능구현

### 안혜진 — 마켓·거래 + 커뮤니티
- **담당 컬렉션:** marketProducts, chats(+messages), communityStats, aiConsultations
- **작업 화면:**
  - 커뮤니티 홈, 저축비율 공유, 랭킹, 또래비교 통계
  - 마켓 홈, 상품 상세/등록, 가격비교 결과, 채팅 목록/채팅방, 동네 인증
- **구현 주요 기능:**
  - 게시글/댓글 CRUD 및 실시간 좋아요(Firestore 실시간 스트림 반영, 캐시 불일치 버그 수정)
  - Firebase Storage 기반 게시글 이미지 업로드 기능
  - 실시간 채팅(스티커/이모지 지원) 기능 구현
  - GPS + Kakao Local API 기반 동네 인증(역지오코딩) 기능 구현
  - 팀 내 잦은 병합 충돌 문제를 실시간 소통 강화(파일 편집 전 공지, 잦은 머지)로 개선 — 팀장 역할 수행

### 이태화 — 공동관리 + 미션·아바타 + 소비심리테스트
- **담당 컬렉션:** groups(+sharedExpenses), missionDefinitions, missionProgress, avatarItems, ownedItems, testResults, financialProducts
- **화면:** 그룹 생성/참여, 권한설정, 공동지출 목록, 미션 목록/출석체크/사진인증/승인, 포인트 상점, 아바타, 소비심리테스트 등 13개
